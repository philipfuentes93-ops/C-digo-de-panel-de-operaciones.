Los cambios se sincronizan automáticamente entre todos los que tengan sesión abierta (vos y el transportista), usando el mismo proyecto Firebase del Panel de Operaciones. Si no hay conexión, se guarda solo en este dispositivo y se sincroniza al reconectar. El mapa se muestra con Google Maps y cada dirección se ubica automáticamente (geocodificación gratuita) — puede tardar unos segundos por despacho. Usá Exportar Excel para descargar la hoja como planilla, o las opciones avanzadas para respaldos técnicos (JSON/CSV).
